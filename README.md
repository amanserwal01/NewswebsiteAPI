This project is a simple **News Website** that fetches and displays the latest news articles using an external news API. It is built using **HTML, CSS, and JavaScript** and dynamically loads news content without needing a page refresh. By default, it shows top headlines and also provides a **search feature** where users can enter keywords to find specific news articles. The website uses modern, responsive design principles, ensuring it looks good on both desktop and mobile devices. Each news article is displayed with a title, description, image, and a "Read More" link that redirects users to the full story. This project demonstrates how to integrate APIs into a web application, handle dynamic content updates, and create an interactive user experience. It’s a beginner-friendly project that combines front-end development with real-world API usage.
